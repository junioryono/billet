# Every kernel option billet's guest MUST carry, and must carry as =y.
#
# ONE FILE, TWO READERS, for the reason internal/runnerrelease gives about the runner version: scripts/build-guest-kernel.sh enables each of these, and scripts/check-guest-kernel-config.sh refuses a built config that does not have them. Held apart, the list that is enabled and the list that is checked drift, and the check then passes for an option the build stopped setting.
#
# BUILT IN RATHER THAN AS MODULES. A microVM boots one kernel and has no initramfs to load modules from, so =m is the same as absent here -- which is why the gate demands =y and refuses a config carrying any =m line at all. moby's check-config.sh accepts either; this is where billet is stricter.
#
# WHERE THEY COME FROM. Firecracker's CI config is the base, and this list is what moby's check-config.sh reported missing on it plus what a CI job needs: measured, that base was missing IP_NF_RAW, IP6_NF_RAW, NETFILTER_XT_MARK, NET_CLS_CGROUP and the nftables set, which surfaces as service containers failing strangely rather than as a boot failure.
#
# Blank lines and # comments are ignored; one option per line, without CONFIG_.
