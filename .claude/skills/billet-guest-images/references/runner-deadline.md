# The runner-release deadline

Part of the `billet-guest-images` skill. Each rule is stated in full, with the measurement or incident behind it.

**The runner deadline starts at the first release newer than yours.** GitHub refuses a self-hosted runner about 30 days after a newer release (`runnerrelease.Grace`, warning at `Warn`), and billet's runners cannot self-update (`DisableUpdate = True` in every JIT config, measured). `billet runner check` once counted from `/releases/latest`, so every later release moved a deadline that had passed: 2.334.0 went stale when 2.335.0 shipped 2026-06-08, and counting from 2.336.0 on 2026-07-20 reported a month in hand for a fleet refused six weeks earlier. `runnerrelease.Resolve` is the one calculation over the installed version and the stable release history, asked by `runner check` and `images pull`. The clock starts at the earliest newer release by publication, not version (measured: v2.285.3 was published 2023-01-30, eleven days after the higher v2.301.1), so the walk scans the whole bounded window rather than stopping at the installed tag, and its bound is the installed release rather than a higher number; running out of budget is recorded (`HistoryComplete`) rather than read as an ending. A version the history does not name is its own answer (`InstalledKnown`): expiry is provable, days remaining are not, and `Current` means only "nothing newer was found" so it is asked after `InstalledKnown`. Exit codes: 0 nothing to do, 2 rebuild due, 3 GitHub already refusing; failing to reach GitHub is an error, not one of the three. `images pull` refuses only a proved expiry (`--allow-stale` skips the lookup) and reports image age as maintenance information (`AgeNotice`, fourteen days) that decides nothing. The pin lives on one line of `internal/runnerrelease/pinned.txt` with its checksum; `runner-release.yml` opens a PR when a release lands, and merging is the gate. The scheduled build installs whatever GitHub has published and records it on the image, which is what `runner check` reads.
