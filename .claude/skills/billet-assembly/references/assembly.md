# The assembly, in full

**A step that only the controller may take is a method of the Controller, and a step a later one depends on returns a proof the later one takes.** `runServer`'s order was the control plane's safety, and three structural tests parsed its source to keep it; any helper extracted from `runServer` escaped them. The order is now types (#417): `BecomeController` is the only way to have a `*Controller`; `ServeWire(ctx, FleetForgotten, AdoptedAuthority)` cannot be called without the two proofs, and `Schedule(wire, AuthorityPublished, opts)` without the publication. Each proof holds an unexported pointer to the controller that made it, and each proof type has a field of its own name, because two struct types with the same fields convert into one another (round 1 of the review: `AdoptedAuthority(fleet)` would have skipped the adoption). Every step refuses a zero proof, another controller's, and a controller that is not held. Outside the package a valid proof cannot be built (its field is unexported), so omitting a step's proof does not compile and passing a zero one is refused at run time (the fixture is in #417's description).

**Only the step that proves a thing makes its proof, and the audit is the type checker's, not a reading of the syntax.** Inside the package nothing stops a function building a proof, so `TestOnlyTheProvingStepsMakeTheirProofs` type-checks the package's production files (exactly those `go list` selects, against export data from the same race variant as the test binary) and holds every way to make one to its maker: a literal however its type is spelled or elided, a conversion, `new`, `copy`, a field written or addressed at any depth of a chain, an in-place overwrite, and a returned type that carries one. A proof here is the type itself, an unnamed struct identical to its underlying type (assignable to it with no conversion), a type of this package declared over either, or a type parameter whose constraint admits one, with shapes compared ignoring struct tags. Closures are audited as their own scope with no maker's permission, and each scope is the declared function's full name, so a method of another type named like a maker is not that maker. A `ControlPlane` is held to `OpenControlPlane` the same way, because a reset field by field would serve the wire with resources the controller never forgot or adopted for. Ten review rounds found the syntactic version's holes one after another (aliases inside functions, named containers, implicit assignment from an unnamed struct, constrained generics); the typed version closed them as classes. It stops an ordinary edit, not an adversary: what it cannot read (`reflect`, `unsafe`, a generic helper over any `T`) the steps refuse at run time where they can.

**Each maker calls its operation once, tests that call's error, and builds its proof after; a maker stays plain.** `TestEachMakerDoesItsStepBeforeItsProof` resolves the operation through the type checker (a local function spelled like it, or a method value held aside, is not the step), requires it called exactly once and named nowhere else, as a statement of the maker's own body, its error bound and tested exactly `!= nil` in the call's if or the next statement, in a branch that ends in a return carrying an error; every return up to that test carries nil or a zero literal, and nothing before it builds or writes a proof. A maker has unnamed results, no defer and no label: named results let a deferred closure rewrite what was returned, and a label lets the error branch jump to the proof. A maker that hands its construction to a closure or helper is refused on purpose, so the order stays readable in its own body; an error is classified in the returned expression, not in a switch around the return (an `else` after the return is refused by revive's indent-error-flow already). `new(T)` with its fields set after the step is accepted.

**A Controller and its ControlPlane are bound to the addresses they were made at.** The proofs name their controller by address, so a copy, or a Controller overwritten with another's value (through an identifier, `*dst = *src` in a generic helper, or `copy`), would keep every proof while changing what it authorised. `held()` requires `c.self == c` and `c.cp.self == c.cp`, recorded by `BecomeController` and `OpenControlPlane`; no audit of the source could follow every such write, and the address check does not have to.

**The node's provider is built only under its deployment lock, and the lock is released on every path.** `OpenNode` reads the certificate, claims the identity it names with the host-wide lock, and only then builds the client and the provider, releasing the lock if anything after the claim fails; a successful open holds it until `Close`, which `cmdNode` defers right after the open's check, in the body of a function literal (`defer f(n.Close())` would close at once). `TestANodeBuildsItsProviderOnlyUnderTheLock` and `TestAnOpenNodeHoldsTheLockUntilClosed` hold both, and the CA test opens a certificate-bearing node through `OpenNode` so the bundle it read is the one it claims with. `Node.Run` says READY=1 once, synchronously, after `NewNodeRunner` and before `RunNodeLoop`; the guest cache is served only through the loop's readiness, with its mounts restored by the serving goroutine itself first.

**The harnesses assemble through internal/app and steer only through app.Steering and ScheduleOptions.NodeRunner.** The end-to-end suite (`internal/e2e/assemble_test.go`) and the replay harness (`internal/replay/stack.go`) open their control plane with `app.OpenControlPlane` and walk the steps `runServer` does; their node processes run `app.NewNodeClient`, `app.NewNodeRunner` and `app.RunNodeLoop`, as `Node.Run` does. What a test must change is a field of `app.Steering` (allocator options, node-plane options, scheduler options, a provisioner wrapper, the queue owner), each applied after what the assembly sets so it can only steer what is there, or the in-process runner in `ScheduleOptions.NodeRunner`. A provisioner wrapper keeps the CLI's adapter concrete, because the scheduler finds capabilities by type assertion (#317 was one hidden behind a wrapper). The wire-protocol scenarios (enrollment, mTLS, revocation, restore) still build a plane alone, on purpose.

**The roles are built in one place, and lint says so.** The depguard rule `appconsumers` lets only `cmd/billet`, the command families under `internal/ops`, `internal/e2e`, `internal/integration` and `internal/replay` import `internal/app`. forbidigo bans `server.New`, `nodeplane.New`, `nodeplane.Handler`, `nodeplane.BootstrapHandler`, `node.New`, `nodeclient.New`, `nodeclient.Run` and `rollout.NewCoordinator` outside `internal/app`, the owning package and tests, and in `cmd/billet` too: its operator-output exemption names the messages it covers rather than exempting forbidigo wholesale. Both were measured at zero before they went in, and probed: an import of `internal/app` from `internal/tfclass`, and `server.New` from `internal/tfpolicy` and from `cmd/billet`, each reported. Once every command family had moved into `internal/ops` (#356 Phase 4), three operator constructors joined the ban, each measured at zero and probed from a family: `alloc.New` (the allocator is `app.NewAllocator(cfg, db)`, so a command charges the control plane's own limits rather than a copy of them; nine hand-built copies were replaced), `state.Open*` (every open is an `app.OpenLedger` mode, except the state package's test template and retirement's restricted handles in `internal/ops/host/serverretire*.go`, exempted by file and only for this ban), and `scaleset.New` (outside `internal/scaleset`, `internal/app` and the replay harness). The backends' and stores' constructors and `awscreds.Default` are deliberately not banned: the families build probes and image pulls with options of their own, and the credential chain is read by every AWS package by design.
