# The version range

Part of the `billet-node-wire` skill. Each rule is stated in full, with the measurement or incident behind it.

**The wire is a range, and the bridge runs one way.** `nodeapi.MinVersion` is 12 and `nodeapi.Version` is 25; registration negotiates the highest both speak (`Negotiate`) and records it on the node's row, which `billet status` reports under `protocol`. The plane decodes bodies with `DisallowUnknownFields` while a node decodes responses leniently, so an old node's registration is a subset of a new plane's struct, while a new node's body that carries a field the old plane does not know hits its strict decoder before any version check runs. Upgrade the server first. A node-first upgrade is refused when its registration carries such a field or the ranges do not overlap, and the node adds its own range to every registration failure so the operator is not left with `json: unknown field "min_version"`; when neither holds, the node registers at the highest version both speak (`TestNegotiatePicksTheHighestVersionBothSpeak` holds the arithmetic), so only the gate on the negotiated version protects what follows.

**`MinVersion` is a promise about meaning, not about whether fields parse.** 11 and below decided a pooled runner's trust from the assignment that caused it to launch, which GitHub may reassign; lowering the floor to make an old fleet connect is offering to be wrong. A declaration has three answers: absent (`DeclaredRange` treats a zero minimum as "speaks exactly the one version named"), valid, and contradictory (a minimum above the maximum), and the third is refused before any of registration's side effects run.

**What each version added, and whether an older peer is refused or reported.** 2: node-contributed capacity and site (refused; a v1 node reads as zero). 7: a destroy may set `CommandResult.Custody` (refused; the shape did not change and the meaning did). 8: ordered EC2 shapes and charged size on the lease (refused). 9: BuildKit cache-mount ceiling (refused). 10: per-shape price (refused). 12: trust and cache scope are properties of a pool (the floor). 13: the range itself and the node's release (`VersionNodeRelease`, reported). 14: `CommandInventory` for the compute barrier (`VersionComputeBarrier`, mirrored as `alloc.BarrierWireVersion`; an older host is named "too old to be asked" rather than asked, because asking burns its single command slot for the whole timeout). 15: `CommandUpgrade` (`VersionNodeUpgrade`, gated where it is sent). 16: the installed manifest digest (`VersionNodeDigest`, reported; a digest from a pairing below this is dropped, not refused). 17: the CodeBuild fleet ARN (`VersionCodeBuildFleet`, refused, because two nodes naming one fleet each advertise all of it). 18: the CodeBuild registration path and region (`VersionCodeBuildRegistrationPath`, reported, since it only decides where the sweep looks). 19: `POST /v1/nodes/{node}/withdraw` (`VersionNodeWithdrawal`, checked where emitted; an older plane answers a bare 404 and the node says the plane is too old to be told). 20: `POST /v1/nodes/{node}/leases/{lease}/cache` (`VersionCacheObservation`, reported; checked where emitted in `nodeclient.Client.RecordCacheObservation`, which returns success without sending below it, because what an older plane loses is one diagnostic column on `job_history` and nothing a job depends on). 21: the tier label on `TrustedRunnerGroupRequest` (`VersionTargetedRunnerGroup`; a plane serving several GitHub targets needs it to know which owner's runner group a node is asking about, so an untargeted request from an older node is answered on a one-target plane and refused naming the version on several, because two organizations can each have a group of that name and guessing would vouch for the wrong owner's policy; the client sends the field only on a wire at or above 21, since the plane's strict decoder would refuse it on an older negotiated wire). 22: `CommandResult.Draining` (`VersionNodeDraining`, checked where emitted in `nodeclient.execute`). A launch a draining node refuses says so in that field, and the plane records it through `alloc.NodeDraining`, which sets `drained = 1` on the host's current registration (fenced on epoch and incarnation) while the host stays live for the destroys its running work needs; `ListPlaceableNodes` then skips it until its next registration clears the mark. The mark is fenced to the process that TOOK the refused command (`pending.takenLedgerEpoch` and `incarnation`, read together at delivery), never the node entry's current fence, which a replacement registering in between would own. Reserved floors are measured over every live host, draining or not (`countFloorLeasesPerTier`, `CountOpenPerTierOnLiveHosts`), because a draining host's leases are running jobs occupying their promised slots; admission modelling keeps the placement fleet's count. An older pairing loses only the memory of the refusal: the plane dispatches launches the node refuses, as it did before, 2440 of them in 23 minutes during one host upgrade (#228). 23: the tier's cache block and the cache authority (`VersionCacheAuthority`, #226): `TierSpec.Cache` carries the normalised `config.CacheSpec`, a completion's destroy carries `Command.CacheAuthority` (the plane's verdict on whether the job's writes may publish), `GET /v1/nodes/{node}/leases/{lease}/cache-authority` answers the Actions cache for a live lease the node holds (`forOwnLease`, never an ended one), `?kind=` selects a cache on the policy route, and the build caches' outcomes ride `CacheObservationRequest`. REFUSED ONLY WHERE AN OLDER NODE WOULD DO MORE than the tier allows, reads included (`config.Tier.NeedsCacheAwareNode`: every `default-branch` tier, whose repository namespace an older node would replace with the pool's wider pre-#226 keys; a trusted pool publishing `off` or `default-branch`; a Docker store or sticky disk turned off or held smaller; an Actions archive below 10GiB), because such a node ignores the block and applies the pre-#226 rule. Placement skips those hosts (`alloc.eligibleNodes` against `alloc.CacheAuthorityWireVersion`, pinned equal by a test), the plane refuses at dispatch, and `pending.minWire` refuses again at delivery, because a process that re-registered older after dispatch must not take the launch; `billet status` names a tier that waits because none of its own hosts is on 23 (`alloc.WaitsForCacheAwareHost`, placement's rule with and without the gate). A node below 23 is never asked for an authority (it answers the zero authority, which writes nothing) and an unregistered client (wire 0) answers an error to retry, never the older answer; the build-cache fields go only to a plane on 23, whose strict decoder knows them, and an observation carrying nothing else is not sent at all. 24: `VersionJobUsage`, two diagnostics. `Job.JobID` (GitHub's workflow-job id, empty for a pooled launch) travels plane to node and needs no gate, because the node decodes leniently and an older one ignores it. `POST /v1/nodes/{node}/leases/{lease}/usage` (`UsageRequest`: an `alloc.JobUsage` summary and an optional `alloc.UsageSeries` blob bounded at 512 KiB so the report fits the 1 MiB body) goes through `forOwnLease`, is validated at the boundary and fenced on the epoch by `alloc.RecordLeaseUsage`; `nodeclient.Client.RecordLeaseUsage` sends it only on 24 and treats an older plane as success. The node sends it from `Runner.destroy` before returning, because the plane releases the lease after the destroy and a report after release is `ErrLeaseNotFound`. 25: `VersionProcessUsage`, what a job measured by its process's own accounting reports (a tart VM): the `oom` group named unmeasured, and energy with the source `process` and no idle share. Checked where sent, in `nodeclient.beforeProcessUsage`: below 25 the report says less, never something else, because an older plane's strict validation knows neither (process energy becomes unmeasured, and memory with no OOM count becomes unmeasured whole, since that plane reads measured memory as a measured count); the downgrade works on a copy of the caller's `Unmeasured`.

**The release string is reduced on ingest.** It is the one free-form value a node puts in an operator's report, and a node is authenticated without being trusted to behave; stored verbatim it is a newline away from forging a row of `billet status`. An absent release is reported, not refused, because it decides nothing about capacity, fencing, identity or destruction.
