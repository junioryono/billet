# The simulated backend

Part of the `billet-providers-local` skill. Each rule is stated in full, with the measurement or incident behind it.

**A sixth backend that starts no compute, for measuring placement rather than running it.** `internal/provider/simulated` holds an instance as a record that reports `Running` until a modelled duration has elapsed and `Running=false, Terminal=true` afterwards, still listed until `Destroy` removes it, as an exited container is. The duration comes from the spec's command, which must be exactly what `simulated.RunFor(d)` renders (a tier gives it through `command:` or `launch.simulated.command`); anything else, including another backend's command or a non-positive duration, is refused, so a tier written for the wrong backend fails the launch rather than modelling something. There are no timers: state is a function of the clock (`WithClock`), which is what makes a replay deterministic. Nothing weakens the contract for being a stand-in: `List` and `Find` error on a done context and under `FailInventory(err)`, the harness's seam for a host whose inventory cannot be read, and never answer short; `Destroy` proves (`TeardownStopped`) only for an instance the store held and removed, answers stopped for an id it never held because the store is authoritative, and refuses another deployment's id; untrusted and unknown work are refused because there is no boundary at all; a name in use on the host is refused; the registration is retained nowhere and no rendering of the provider, host or instance contains it. Two providers over one `simulated.Host` model two deployments on one machine and are kept apart. `config.ProviderSimulated` is `Valid` and `RunsOnHost` so the ledger and the wire register it in a test and charge the tier request, `Config.Validate` refuses it anywhere a file could name it, `cmd/billet` refuses to construct it, and `TestNothingOutsideATestImportsThisPackage` walks the module to prove no non-test file imports it. The end-to-end stack takes it through `withBackend` and runs without docker; `internal/e2e/simulated_test.go` proves a lease is charged, held through the modelled duration and after the instance stops, and released only by GitHub's completion through the ordinary destroy-then-release path.
