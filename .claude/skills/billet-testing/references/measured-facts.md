# Measured facts

Part of the `billet-testing` skill: what was measured, dated where it was recorded.

- A mutation run over a Python module can leave a `__pycache__` entry compiled from the MUTANT beside the restored source: a swap of two lines keeps the size, the restore lands in the same second, and Python's mtime-and-size check then executes the mutant while the traceback prints the restored lines (2026-09-09, `module_utils/endpoint.py`, the zone-before-unmapping case "failing" on a correct source). The collection's Python checks set `sys.dont_write_bytecode = True`; a mutation script over a Python file removes its `__pycache__` after each restore.
- A fake updater that must dial a Unix socket re-executes the test binary through a two-line shell script with an explicit mode and `-test.run '^TestFakeUpdaterProcess$' -- "$@"`; the Go helper finds `--ack-path`, dials and writes, dials and exits for EOF, or never dials for the accept timeout. A shell alone has no portable socket client. Use a cleaned-up `os.MkdirTemp("/tmp", ...)` for socket directories: macOS `t.TempDir` paths exceed the Unix address limit. Tests changing `ackWait`, `underSystemd` or `systemdRun` stay serial. A fake service manager clears its child's inherited environment and forwards only explicit `--setenv=NAME` entries: inheriting the parent test's whole environment hid missing credentials in the first transient-unit implementation. Assert the configured DSN and all three AWS credential variables reach the re-executed updater together, with both a session token and an empty token, and that their values never appear in argv.
- Named pipes cannot replace this socket: a FIFO with no writer reads EOF immediately, and holding a writer open hides an updater's death. On Darwin Go does not poll FIFOs (kqueue, Go issue 24164), so `SetReadDeadline` refuses with "file type does not support deadline"; reported by the probes for #98 on 2026-09-06. Unix sockets support the bound on both platforms.
- Discarded-error vacuity: seven instances (five in `internal/alloc`, two in `internal/github`).
- `errcheck` on tests: 19 sites, two real bugs.
- The onboarding fake's concurrent slice read survived six clean `-race` runs.
- A 700ms mutex stall against a 300ms TTL reproduced `TestACancellationInsideTheLongPollStillDrains`'s CI failure exactly, and only under the old heartbeat ordering (`Listener.heartbeatLock` is the seam).
- A lease that must survive a stall is proved on the allocator's clock, never by sleeping past a wall-clock TTL against the real ticker: `TestRenewalOutlivesTheShutdownRelease` slept two 900ms TTLs and failed on a loaded CI runner (2026-10-02, the test taking 21s) because a pass whose SQLite write outran its TTL/3 budget renewed nothing. Since 2026-10-08 those tests run in a `testing/synctest` bubble, where the allocator's default clock, the loop's ticker and each pass's budget are one fake clock; `throughTwoTTLs` in `internal/server/listener_test.go` sleeps a heartbeat interval, waits for the bubble to go quiet and reaps, six times, and the twenty `internal/server` tests moved into bubbles took 17.96s together under `-race`, one at a time, before the move and 3.09s after it.
- `TestImportGenerationConfirmsRemovalAfterCallerAndRemovalDeadlinesExpire` set one 20ms knob for two opposite purposes and produced two distinct CI failures under a 30ms stall.
- Test build tags: exactly one (`//go:build unix`) across the suite.
- Every version test injected `v1.2.3` while the release build injects `1.2.3`; `version.Compare` refused the bare form as "not a release", all four downgrade guards were could-not-tell on every release binary for nine releases, and a stale rollout downgraded a control plane (2026-09-05). The shape a test injects has to be the shape the build injects, read from the build config, not assumed.
- A fake host that ignored the fence's reason argument (`_ string`) passed fourteen ordering tests while every real commit and rollback cordoned the host (2026-09-05); a fake that drops an argument the real thing judges is the vacuous shape, and `internal/hostupgrade/fence_test.go` hands the argument to the real ledger instead.
