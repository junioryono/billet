# Changing the node wire

A checklist. The rules behind each step are in `billet-node-wire` (its `references/versions.md` holds the full table of what each version added).

1. **Decide what an older peer does.** The plane decodes bodies strictly (`DisallowUnknownFields`, and one JSON value with nothing after it) and a node decodes responses leniently, so a new field a node sends hits an old plane's strict decoder, and one the plane sends is ignored by an old node. For each direction, decide whether an older peer is refused or reported. Refuse only when the old meaning would be wrong, not merely absent.
2. **Add the version.** Raise `nodeapi.Version` by one and name the step with a constant beside the others in `internal/nodeapi/nodeapi.go` (`VersionNodeWithdrawal`, `VersionJobUsage` and so on), with a comment saying what it carries and why an older peer is refused or reported. `nodeapi.MinVersion` is a promise about meaning: never lower it to make an old fleet connect.
3. **Gate where it is sent and where it is read.** After registration, a node checks the negotiated version before sending what an older plane would refuse (`c.WireVersion()` in `internal/nodeclient`), and the plane checks it before sending a command an older node does not know. Registration itself is sent before any version is negotiated (`WireVersion` is zero until it succeeds, and `Register` sends the installed digest regardless), so a registration field is gated by the plane after negotiation, and one an older plane's strict decoder refuses is what makes that upgrade server first. Enrollment has no negotiated version at all, and its compatibility is handled on its own. Apply the field's compatibility policy at the boundary where it matters, sending or receiving. Drop an unsupported value only where its absence has defined, safe meaning (`negotiatedDigest` in `internal/nodeplane/plane.go` drops a manifest digest below `VersionNodeDigest`, and a host that cannot say is a state everything downstream reads), and test an older negotiated version carrying a non-empty new field. Refuse an operation whose meaning the peer cannot honour (the plane refuses a launch whose restrictive cache policy an older node would ignore, in `internal/nodeplane/runner.go`). A diagnostic extension that is compatible by design needs no receiver gate. Upgrade the server first. A node upgraded first is refused at registration only when the ranges do not overlap or the registration itself carries what the older plane refuses; otherwise it registers at the highest version both speak (`nodeapi.Negotiate`), so the gate on the negotiated version is what protects everything after registration.
4. **Record it.** Add the version's line to the table in `billet-node-wire`'s `references/versions.md`, and update that skill's "version range" wherever it names the current maximum. Write the new version's golden fixtures with `BILLET_UPDATE_FIXTURES=1 go test -run TestTheWireEncodingIsPinned ./internal/nodeapi/`, which creates `testdata/wire/v<N>/`; never rewrite an earlier version's directory, because `TestEverySupportedVersionsBodiesStillDecode` holds that every version from 25, or `MinVersion` if higher, keeps its fixtures, that each body still decodes as its receiver decodes it and keeps every field it had, and that no field it named was narrowed or retyped. A change to any wire type's encoding fails `TestTheWireEncodingIsPinned` until you do, renamed Go fields of `alloc.Lease` included.
5. **Prove both directions.** Test a peer at the new version and one at the version below: the refusal or the report, by its sentinel or its message, not only that an error came back.

A route runs the authentication its wire applies before it reads a body (`handler.authenticated` in `internal/nodeplane/http.go`), and a registration proves only who a node is; a command is what proves what it may do. There are three wires: the fleet wire authenticates the node's certificate; a loopback wire carries no certificates, and `authenticated` answers that it does not authenticate rather than naming an anonymous caller; and enrollment, served on the bootstrap listener to a node that has no certificate yet, decodes a bounded body and spends the join token in the same call that records the request (`billet-node-wire`).
